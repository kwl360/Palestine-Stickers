# Palestine Stickers 🇵🇸
Android WhatsApp animated sticker pack project.

## Build
GitHub Actions workflow **Build Android APK** builds a debug APK on every push to `main`. Download the APK from the workflow's **Artifacts** section after a successful run.

## Required assets
Place `sticker_01.webp` through `sticker_12.webp` and `tray.png` in:
`app/src/main/assets/stickers/palestine_boy/`

**Status:** The 12 animated WebP assets and tray icon are not yet committed. The project is not ready to install as a functional WhatsApp sticker pack. An APK build alone does not guarantee WhatsApp compatibility.
